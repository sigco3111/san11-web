# 삼국지: 천하 (비공식 팬 프로젝트)

코에이 『삼국지11』의 시스템을 참고해 만드는 **비공식 독립 팬 제작 웹 시뮬레이션**입니다.
원작 게임의 파일·이미지·음악 등 리소스는 일절 포함하지 않으며, 역사 인물의 이름과 연도 같은 사실 데이터와
팬이 정리한 수치 자료만 참고했습니다. 코드·데이터·초상화는 이 저장소에서 독립적으로 작성/생성되었습니다.

**라이브 (v0.1 시험판): https://sigco3111.github.io/san11-web/**

## 현재 상태 (v0.1 시험판)

이 저장소는 **개발 중인 첫 시험판**입니다. 기획서 전체가 아니라 아래 범위만 구현되어 있습니다.

### 구현된 것
- **3D 저폴리 지도** (Three.js): 대략적인 중국 지형·황하/장강·산맥, 42개 도시 표시, 회전/확대/이동 카메라 (PC·모바일 터치)
- **시나리오 3개**: 황건의 난(184) · 반동탁연합(190) · 영웅집결(251)
- **군주 선택 → 턴제 진행** (1턴 = 10일, 행동력)
- **기본 내정**: 상업/농업 개발, 징병, 무장 이동
- **기본 군사**: 부대 출진(검/창/극/노/기), 지도상 이동, 단순화된 공성전과 도시 함락
- **세력 AI**: 모든 세력이 내정·징병·공격을 스스로 판단 (유휴 부대 재임무 부여 포함)
- **위임·세력 전환 (핵심 기능)**: 자기 세력을 AI에 위임하면 세계가 샌드박스처럼 자동 진행 (속도 조절).
  관전 중 다른 세력 도시를 눌러 **어느 군주로든 참가** 가능 — 턴 경계에서 인계, 롤백 없는 연속 세계
- **세력 멸망 처리**: 멸망 시 다른 세력으로 계속 / 관전 계속 / 종료 선택
- **자동 저장**: 매 턴 브라우저 로컬 저장 (`cheonha-xi-web.save.v1`, 다른 게임 세이브와 분리된 전용 키), 이어하기 복원
- **무장 670명 데이터**: 능력 5종·병종 적성·특기 22종(한글 명칭)·등장/사망 연도
- **초상화**: AI 생성 수묵 담채 초상화 **514/670장** 반영 (아틀라스 연결), 미완성분은 더미 이미지로 표시 (생성 진행 중, 완료되는 대로 교체)
- **전법·계략·기력**: 병종별 전법(창·극·노 3종+기병 3종+병기·수군 전법)과 화계·혼란·위보·진정·소화·복병·요술·낙뢰가 공성전·야전에서 발동, 부대 명령으로 직접 발동도 가능 (자체 명명·자체 수치), 부대 기력 0~100
- **병기·수군**: 충거·정란·목수·투석기(공방 생산)와 주가·누선·투함(조선소 건조, 강·바다 기동), 연안 육상↔수상 교전
- **일기토·설전**: 방침 4종·투지 게이지·필살 커맨드(필살기·급소·무쌍·퇴각·암기·위퇴각)의 일기토와 화술 5종(질타·강변·반박·경청·도발)의 설전. 외교·등용 협상 결렬 시 설전이 벌어지기도 함
- **외교**: 세력 간 관계 5단계, 사절 파견(친선)·동맹·정전·원군요청·항복권고, 수신 제안은 수락/거절 결정
- **인재 수색·명품**: 도시 수색으로 재야 무장·명품 발견. 명품 6종(명마·활·검·서적·장병·옥새) 효과 적용
- **기교 연구·능력연구**: 기교P로 8계통 기교 연구와 세력 단위 능력연구 4계통(공격·방어·계략·내정, 특기 습득 포함)
- **시설 건설·흡수합병**: 내정시설 건설과 같은 시설의 흡수합병(레벨업), 신 내정시설 10종, 야전시설(진·채·토루·함정 등)과 제방 파괴·수몰
- **관직·군사·군단**: 공적에 따른 관작 승진(주자사~황제), 지력 70+ 군사 임명, 도시 묶음 군단 편성(방침: 위임·도시공략·세력공략)
- **상인 거래**: 도시 상인과 금↔병량 거래 (환율 변동)
- **재해·치안·적(賊)**: 역병 발생(도시 표시, 병사·금·병량 감소), 치안 악화 시 적 출현·시설 파괴
- **시야(전쟁 안개)**: 직접 지휘 시 내 도시·부대 주변만 상세 공개, 위임·관전 중엔 전체 공개
- **포로·연감·대시보드**: 전투 포박·석방·포로 등용, 주요 사건 연감, 세력 현황 대시보드
- **야전·요격**: 이동 중인 적 부대와 접근하면 교전하며 진격이 멈추고, 병력이 적어지면 아군 도시로 퇴각
- **인재 등용**: 도시의 재야 무장을 금·행동력으로 영입 (성공률은 사자 매력·상대 매력·충성·군주 매력 기반 자체 수치), AI도 같은 규칙으로 등용
- **특기·적성**: 특기 22종 전부 효과 적용 (공격·방어·이동·계략·수입·징병·등용·완강·수완·신행·미끼·이간·귀납·훈련·치안 등, 전부 자체 수치), 병종 적성 C~S 공격 보정

브라우저를 닫은 동안의 진행 따라잡기(기획상 선택지), 밸런스 조정 전반.

- 실UI 검증(클라우드 브라우저): 외교 수신 5종 수락/거절 전 격자, 명품 효과, 일기토 필살 커맨드·설전 카드,

### 데이터 출처와 권리 구분
- **코드·지형·초상화**: 이 프로젝트에서 독립 작성/생성. 반영된 초상화 514장 전량 AI 신규 생성이며 외부 원작 아트는 0장입니다.
- **역사 사실**: 인물 이름·한자·생몰연도(사료 기반분), 도시 이름·위치, 184/190년의 세력 소속과 판도 골격.
- **독자 작성 데이터** (2026-10-30 사용자 승인으로 전환): 무장 능력 5종·병종 적성·특기(명칭·효과 자체 명명)·등장 연도·
  도시 경제/병력 수치·충성도·태수 배정·251 '영웅집결' 가상 배치 전부.
  `tools/gen_data.py`, `tools/gen_scen.py`의 자체 루브릭으로 생성하며 원작 게임 수치를 참조하지 않습니다.
  유명 인물 약 120명의 수치는 역사적 평가에 근거한 프로젝트 자체 평가값이므로 원작과 다릅니다.
- 한자→한글 독음: sigco3111/dragon 저장소의 사전을 참고.
- 미검증 한글명 일부는 한자 표기로 남아 있을 수 있음 (데이터에 `name_confirmed` 플래그)

