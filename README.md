# 삼국지: 천하 (비공식 팬 프로젝트)

코에이 『삼국지11』의 시스템을 참고해 만드는 **비공식 독립 팬 제작 웹 시뮬레이션**입니다.
원작 게임의 파일·이미지·음악 등 리소스는 일절 포함하지 않으며, 역사 인물의 이름과 연도 같은 사실 데이터와
팬이 정리한 수치 자료만 참고했습니다. 코드는 이 저장소에서 독립적으로 작성되었습니다.

## 현재 상태 (v0.1 시험판)

이 저장소는 **개발 중인 첫 시험판**입니다. 기획서 전체가 아니라 아래 범위만 구현되어 있습니다.

### 구현된 것
- **3D 저폴리 지도** (Three.js): 대략적인 중국 지형·황하/장강·산맥, 42개 도시 표시, 회전/확대/이동 카메라 (PC·모바일 터치)
- **시나리오 3개**: 황건의 난(184) · 반동탁연합(190) · 영웅집결(251) — 원작 배치를 팬 정리 데이터에서 변환
- **군주 선택 → 턴제 진행** (1턴 = 10일, 행동력)
- **기본 내정**: 상업/농업 개발, 징병, 무장 이동
- **기본 군사**: 부대 출진(검/창/극/노/기), 지도상 이동, 단순화된 공성전과 도시 함락
- **세력 AI**: 모든 세력이 내정·징병·공격을 스스로 판단
- **위임·세력 전환 (핵심 기능)**: 자기 세력을 AI에 위임하면 세계가 샌드박스처럼 자동 진행 (속도 조절).
  관전 중 다른 세력 도시를 눌러 **어느 군주로든 참가** 가능 — 턴 경계에서 인계, 롤백 없는 연속 세계
- **세력 멸망 처리**: 멸망 시 다른 세력으로 계속 / 관전 계속 / 종료 선택
- **자동 저장**: 매 턴 브라우저 로컬 저장 (`cheonha-xi-web.save.v1`, 다른 게임 세이브와 분리된 전용 키)
- **무장 670명 데이터**: 능력 5종·병종 적성·특기(한글 명칭)·등장/사망 연도
- **초상화**: AI 생성 수묵 담채 초상화 **204/670장** 반영, 미완성분은 더미 이미지로 표시 (생성 진행 중, 완료되는 대로 교체)

### 아직 구현되지 않은 것 (후속 라운드)
전법·계략·기력, 일기토·설전, 병기·수군, 시설 건설(내정시설), 흡수합병·능력연구(PK 요소), 외교·동맹,
인재 등용·수색, 관직·군단, 명품, 재해, 안개(시야), 도로 그래프 기반 이동, 밸런스 조정 전반.
즉 **삼국지11의 완성된 이식이 아니라, 핵심 구조(위임·세력 전환 포함)를 검증하는 1차 골격**입니다.

### 데이터 출처와 권리 구분
- **코드·지형·AI 생성 초상화**: 이 프로젝트에서 독립 작성/생성.
- **역사 사실**: 인물 이름·한자·생몰연도(사료 기반분), 도시 이름·위치, 184/190년의 세력 소속과 판도 골격.
- **독자 작성 데이터** (2026-10-30 사용자 승인으로 전환): 무장 능력 5종·병종 적성·특기(명칭·효과 자체 명명)·등장 연도·
  도시 경제/병력 수치·충성도·태수 배정·251 '영웅집결' 가상 배치 전부.
  `tools/gen_data.py`, `tools/gen_scen.py`의 자체 루브릭으로 생성하며 원작 게임 수치를 참조하지 않습니다.
  유명 인물 약 120명의 수치는 역사적 평가에 근거한 프로젝트 자체 평가값이므로 원작과 다릅니다.
- 초상화 4장(idx 98/289/343/660)은 사용자가 승인한 원작 게임 초상화라 공개 배포하지 않고,
  공개본에서는 더미 이미지로 표시합니다 (AI 생성 초상화로 교체 예정).
- 한자→한글 독음: sigco3111/dragon 저장소의 사전을 참고.
- 미검증 한글명 일부는 한자 표기로 남아 있을 수 있음 (데이터에 `name_confirmed` 플래그)

### 로컬 실행 (현재는 로컬 검증용)
```bash
cd san11-web && python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
