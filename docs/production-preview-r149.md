## 원기획과 한정 범위

AI도 같은 명령을 기존 명령 뒤에 실행한다. 금1200 보존/잔여AP/인접 적 도시 거리12 미만/주둔6000 이상/주력4병장 최대재고<min(주둔병-3000,6000) 조건. 기존 출진보다 생산을 강제하지 않는다.
